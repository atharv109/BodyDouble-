Investigate the double. Leave production running.

Body Double is an incident-response agent for teams on Vultr. When a server looks hacked, it snapshots it, investigates an exact copy in a sealed room, and proposes containment for the real server that a human approves.

A small team that suspects a breach has two bad options: poke the live server and risk tipping off the attacker, or shut it down and take the business offline. Body Double works on the copy instead.

The copy never boots its own OS: the twin starts from a forensics ISO, mounts the cloned disk read-only, and runs anything suspicious only in no-network gVisor containers with a fake DNS resolver that catches the beacon.

  • Writes to production before approval: 0. Packets out of the investigation: 0. Containers left running: 0.
  • Built on Vultr Cloud Compute, Snapshots, custom ISO, VPC, firewall groups, the Vultr API and Serverless Inference.
