## Design Context

### Users
The primary user is the one technical operator responding to a 2 a.m. server incident; the secondary audience is a hackathon judge evaluating the product quickly. The interface must make investigation state, evidence, and the only production-changing approval obvious under pressure.

### Brand Personality
Calm, forensic, and controlled. Body Double should feel like a precise incident-response instrument: the original server stays protected while its sealed twin absorbs the dangerous work.

### Aesthetic Direction
An industrial, near-black observation room with restrained brass for agent activity and red reserved for actual findings. The existing IBM Plex Sans/Mono system, 2px geometry, hairline frames, and “latch” motion remain the product language. The reference informs hierarchy—a compact status band, one dominant chronological log, and a narrower task rail—without literal imitation.

### Design Principles
- Make the current state and next human action legible within seconds.
- Keep one dominant information path; progressively disclose raw logs and secondary evidence without removing facts or source labels.
- Motion communicates navigation, live arrival, and state change only; it is short, transform/opacity based, and absent under reduced motion.
- Production and twin remain visually distinct, and nothing implies production changed before explicit approval.
- Compose for 390px rather than merely shrinking desktop; preserve keyboard access, readable contrast, and every capability.
